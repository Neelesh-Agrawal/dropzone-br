DROPZONE — Visual Reference Pack

Purpose: Give this file to the coding/design agent as a visual benchmark for the browser battle-royale project. It covers the experience from loading and lobby through deployment, gameplay, loot, weapons, attachments, map and results.

Important: These are visual and interaction references only. Do NOT copy PUBG, Call of Duty, Warzone or other games' protected artwork, logos, maps, characters, weapon models, sounds or exact UI. Recreate the design principles with original assets and an original visual identity.

Visual target

  • Premium browser game, not a low-poly tech demo.
  • Grounded tactical realism with restrained color.
  • World first; HUD supports gameplay.
  • Believable weapons and character proportions.
  • Map has recognizable POIs, roads, elevation, cover and combat spaces.
  • Loot is understandable at a glance.

Screen-by-screen build checklist

1. Loading / boot

  • Dark atmospheric background or animated world silhouette.
  • Original DROPZONE logo and progress indicator.
  • One short gameplay tip.
  • No giant spinner or empty screen.

2. Home / lobby

  • Character/squad is the visual anchor.
  • Large primary Play action.
  • Secondary navigation: Loadout, Armory, Profile, Settings.
  • Level/XP visible without clutter.

3. Deployment

  • Large readable terrain below player.
  • Drop trajectory/marker.
  • Minimal HUD.
  • Strong sense of scale.

4. Gameplay

  • World occupies almost the entire screen.
  • Compass at top.
  • Squad state in one consistent area.
  • Minimap in a corner.
  • Weapon/ammo information near lower-right.
  • Interaction prompts only when relevant.

5. Loot

  • World item has clear silhouette.
  • Pickup prompt gives item name and action.
  • Rarity is a secondary cue.
  • No giant floating labels.

6. Attachments

  • Scope/optic/grip/mag/muzzle are physical weapon components.
  • Weapon changes visually when attachment is equipped.
  • Attachment screen can show clean stat comparison.

7. Tactical map

  • Readable terrain and POIs.
  • Player and squad markers are distinct.
  • Safe-zone boundary is obvious.
  • Ping/marker system is easy to understand.

8. Match result

  • Strong victory/defeat hierarchy.
  • Placement, eliminations, damage, survival time and XP.
  • Clear Play Again / Return to Lobby.

Map reference principles

Official PUBG material describes battle-royale maps as spaces containing cities/towns, varied terrain and recognizable POIs; Erangel is 8×8 with grasslands, mountains, cities and towns, while Sanhok is a smaller 4×4 map intended for faster encounters. Use these only as structural references.

Weapon reference principles

  • Original weapon silhouettes, not copies of commercial firearms.
  • Clear roles: AR, SMG, DMR, shotgun, sniper.
  • Attachment slots visibly alter the weapon.
  • Believable metal/polymer/rubber/glass materials.
  • Weapon large enough to recognize instantly.
  • ADS/scope view has a clear sight picture and minimal UI.

Player reference principles

  • Use one original tactical character for V1 rather than many low-quality characters.
  • Strong silhouette and readable equipment.
  • Layer clothing, armor, backpack, helmet and weapon.
  • Simple but believable idle/run/aim/reload animations.
  • Character should work in lobby and in-game.

Functional requirement

Visual quality comes after a working game loop. The agent must not polish a static lobby while the match is broken.

  1. Two browsers connect.
  2. Players move and see each other.
  3. Players shoot and receive server-authoritative damage.
  4. Loot can be picked up.
  5. Attachments can be equipped.
  6. Map and safe zone work.
  7. Complete match can end and return to lobby.
  8. Then increase visual fidelity using this pack.
